AI Quiz Generator

Most AI quiz tools fill the wrong answers with random filler, so a wrong pick tells you nothing. I built one that maps the content first, then writes every wrong answer around a real misconception. When a learner misses a question, you know exactly what to reteach.

    How it works

    Four steps, one human in the loop

    01

    Map

    Objectives, concepts, prerequisites and misconceptions, drawn as a graph. An SME can edit the map before any questions are written.

    02

    Write

    Questions follow prerequisite order and lean toward apply and analyze. Every wrong answer targets one misconception.

    03

    Review

    An AI rubric and rule-based checks review every question. Anything both of them flag gets fixed first.

    04

    Export

    Moodle GIFT, CSV for bulk upload, Markdown for SME review, or the full project to reload later.

    Design decisions

    Why it's built this way

    Grounded in learning science

    • Diagnostic distractors: a wrong answer tells you what the learner believes, not just that they missed it.
    • Prerequisite mapping: concepts get tested after the ideas they depend on, and gaps in coverage show up on the map.
    • Feedback on every option that speaks to the specific misconception, without shaming.
    • Item-writing rules built in: no "all of the above," no length giveaways, negatives in caps, a balanced answer key.

    Doesn't trust the AI blindly

    • Structured output: every AI response is validated against a schema, and errors get sent back for a retry.
    • Two reviewers: an AI grading an AI misses things, like a key that's "b" five times in a row. Plain code catches those every time.
    • Human checkpoint: the concept map is editable before questions are written. That's where the SME belongs.
    • Tested: 44 automated tests run on every change to the code.
